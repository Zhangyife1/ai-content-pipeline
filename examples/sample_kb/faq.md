# 星尘 AI 平台常见问题

## 收费模式

平台按内容生成次数计费：

- 免费版：每月 50 次生成
- 专业版：每月 5000 次生成，价格 299 元/月
- 企业版：不限次数，按年付费，支持私有化部署

## API 限流

标准 API 限流为每秒 10 次请求；企业版可调整到每秒 50 次。超过限流会返回 HTTP 429，并附带 `Retry-After` 响应头。

## 支持哪些发布平台

目前官方支持微信公众号、知乎专栏、官网 CMS、头条号。B 站专栏与小红书在规划中。

## 如何保证内容不重复

系统对每篇生成内容计算 64 位 SimHash，与历史内容对比 Hamming 距离，距离小于等于 3 即判定高度相似并自动重写。

## 效果数据如何回流

发布成功后，系统通过平台 API 采集阅读量、互动率、转化数据，并按 UTM 参数归因到具体内容与 Prompt 版本，形成优化闭环。
