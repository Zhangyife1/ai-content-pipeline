# 星尘 AI 内容平台产品手册

## 产品定位

星尘 AI 内容平台（Stardust AI）是一套面向增长团队的 AI 内容生产与分发系统，覆盖知识库投喂、内容生成、三层质检和多渠道发布。

## 快速开始

### 配置 API 密钥

1. 登录控制台，进入「开发者中心」。
2. 点击「创建 API 密钥」，密钥以 `sk-st-` 开头。
3. 将密钥配置到环境变量 `STARDUST_API_KEY`，服务启动后自动生效。
4. 密钥支持权限范围：`read`（仅检索）、`write`（生成与发布）、`admin`（全部权限）。

密钥泄露后可在控制台一键吊销，5 分钟内全链路失效。

## 知识库管理

平台支持 Markdown、HTML、PDF 三种格式的知识文档。建议单个文档不超过 10 万字符，超过后系统会自动按标题层级切分。

### 增量更新

平台使用内容指纹（BLAKE3）做增量比对：源文档变更后只重建发生变化的片段，未变更片段直接保留。删除内容采用逻辑删除，历史版本可在「版本时间线」中回溯。

## 内容生成

### 生成模式

- 文章：多步生成链，平均耗时 3 分钟/篇，支持公众号、知乎、官网 CMS。
- 摘要：单步生成，200 字以内。
- FAQ：基于知识库自动生成问答对。
- SEO 元数据：自动生成标题标签、meta description、关键词与 URL slug。

### 生成质量

生成内容会经过三层质检：SimHash 重复率检测、RAG 事实交叉验证、格式规范检查。任一层不通过即进入人工复核队列。

## 发布能力

平台支持定时发布与手动立即发布。发布任务失败会自动指数退避重试（1s/2s/4s），最多 3 次；认证失效会触发 Token 刷新后重试。

## 数据与隐私

知识文档默认只存储在内网向量数据库，不会用于模型训练。支持私有化部署，所有模型组件均可本地部署。
